# Flowglass 3080 实例修复与验收

2026-09-20，在用户已安装的 `http://127.0.0.1:3080/` 内置浏览器页面测试。视口为 1920×1080，同时检查宿主全屏和约 860px 右侧栏（Flowglass 内容宽 848px）。保留原有未提交 UX 改动，本轮没有发布新版本。

## 修复

- **并发选择器**：HTML → React 转换保留 option 的空字符串值；表单控件仅在服务端值改变时同步，避免普通刷新覆盖刚选择的值。增加分支编号、模型和思考强度的可访问名称。
- **三列布局**：按用户明确反馈恢复左侧子代理、中间用户/助手主干、右侧工具调用。窄栏保留三列并提供画布横向滚动；长行不再压缩到相互重叠。保留缩放、搜索、标记和详情入口。
- **关系图轮次**：拓扑的第 N 轮不能当作继承前缀之后的日志 turn。按保存的任务输入及提交时间定位；重复候选无法区分、或没有本轮输入时不显示旧回答，也不提供错误的分叉锚点。保存的输入目前仍限于 240 字符。
- **工作目录及历史**：原生 `sessionInfo` 支持 `SessionRecord.header.id`，客户端对会话初始化时的查询失败进行有界重试，切换时清理旧目录。修复冷启动时目录未解析、历史误落默认范围的情况。
- **冷分叉读取**：当前安装的 Harness `readSession` 在冷分叉上抛出 `seeded session constructor seed must equal its inherited prefix`。仅针对此异常，使用同一 `sessionQuery` 服务的 `listEvents` 和 `readEvent` 原始日志接口，按不超过 50 条后文分页并校验完整性。其他错误继续报告失败，不修改持久会话日志。

### 本轮实测

使用内置浏览器真实 3080，1920×1080，侧栏宽 848px。测试模型提示均明确禁止工具调用和文件读写。

1. 既有两个测试分支继续发送，均回复 `FLOWGLASS_SCROLL_OK`。发现并继续修复发送后范围退回会话树、异步增高后未贴底。
2. 修复后继续发送，两个分支均回复 `FLOWGLASS_FINAL_OK`，仍仅显示当前两个分支，开工区已折叠。
3. 从单分支发起 1→2，两个新分支均回复 `FLOWGLASS_FORK_OK`，开工区已折叠；测试记录保留。
4. 真实长对比：主滚动最大值 574px，进入时 scrollTop=574；向上阅读后 scrollTop=0，手动刷新及后续轮询保持0。内层对比 overflow 为 visible。
5. 实际 React 稳定面板的独立测试页：初始900/900、新增960/960；向上阅读到698后新增和容器缩放均保持698；返回底部后新增1140/1140。此项为合成测试，未冒充真实会话。
6. 实际点击标记图标打开标记面板；点击带入图标显示来源预览，确认追加到原本为空的当前会话草稿，前后会话 scope 一致；随后清理仅由本次测试产生的草稿。
7. 27 套 smoke 通过，Flow 增加概览过程、关闭幂等性、任务范围重挂回归，合计213项；原生静态契约增加带入/错误透传，合计51项。生成物与两个静态包校验通过。

冷启动期间曾出现 Harness 自身 locale subscriber 的 unknown session 日志和一次5秒面板超时，随后自动恢复；未修改宿主包，不把该启动日志宣称为已经修复。日常发送与页面稳定后的回归没有依赖清空用户数据。

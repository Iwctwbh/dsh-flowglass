| 能力 | 当前行为 | 边界 |
| --- | --- | --- |
| 导航 | 当前会话 / 并发任务；概览 / 对比 / 关系图；子代理面包屑可返回祖先 | 保存的 `compact/detail/map`、历史和跟随偏好继续可读 |
| 阅读层级 | 系统上下文默认折叠；消息正文优先；技术信息按需展开；来源会话独立于分支数量 | 折叠不删除事件，不改变原有框选上下文 |
| 自适应详情 | 窄栏替换、常规宽度覆盖、宽面板并排；返回 / Escape；键盘焦点恢复 | 宿主全屏由 Harness 控制；真实原生 tab 全屏联动仍待认证页面验收 |
| 查找与筛选 | 消息、工具输入输出及错误文本查找；类型 / 运行 / 失败筛选；需要关注入口 | 明确区分当前已加载节点与全会话已记录日志；结果最多呈现 200 个节点并提示缩小条件 |
| 标记 | 本浏览器保存 Session、类型、seq、备注；定位时补足历史窗口并打开详情 | 按 bundle 与工作区隔离；备注不写入 Session；不存在、归档或身份不匹配的节点解释失效 |
| 分支概览 | 来源只显示一次；每个分支显示状态、当前工具、最近结论与异常 | 仅使用已有数据；不自动推断答案质量或调用模型 |
| 对比 | 完整输入相同时声明已对齐，共享输入只显示一次；支持仅看差异 | 同一个 turn 数字不是同源证明；无法证明时显示“未对齐”，缺少结果与运行中状态保留可见 |
| 结论复用 | 选择 2–4 条已完成助手结论，预览来源 / 轮次 / 节点，再追加到目标草稿 | Host 再验证节点已完成；取消不改草稿；此入口不自动发送；摘要和上下文存在体积上限 |
| 关系图 | 适应画布、定位选中、恢复布局、缩放、平移与键盘操作 | 保留历史轮次、沿用和派生关系；关系图允许平移 |
| 只读回放 | 按 durable event 的 seq 前缀重建，前进 / 后退、回到最新 | 不注入 live overlay，不读取子代理未来日志；未提供按墙钟时间自动播放，不重执行任何任务 |
| 本地导出 | 当前视口可见节点的 JSON 诊断摘要或 SVG 节点快照，下载前预览 | 默认不包含正文；显式勾选才附可见摘要；不是原始日志导出，也不是带图片 / 全部连线的像素截图 |
| 稳定编辑 | Flow 头部 / Composer / Inspector 使用独立 React 区域；草稿恢复与详情阅读保持 | 普通 Toolbox 工具继续 `{html,state}`；未把整张画布迁为 React 图编辑器 |
| 发送恢复 | 逐分支记录 create/configure/send 与成功 / 失败 / 未知状态；已创建 Session 复用；成功分支不重复发送 | 未知发送先核对可用事件，无法证实时保留未知；不承诺服务端未提供的 exactly-once |
| 工具规则 | 设置先展示摘要，再展开编辑；保留规则顺序、启停与原有存储 | 官方插件详情仍是设置入口 |

## Toolbox 三形态能力矩阵

本节落实计划第 11.6 节。新 Host 功能复用既有 `sessionQuery` / `makeSessionLogReader`；没有增加 Flowglass 专用 Host 注入。缺少日志服务或读取失败会明确提示，不能把失败的读取当作空会话。

| 能力 / 契约 | 独立静态 Flowglass | 完整静态 Toolbox | 源码动态 Toolbox |
| --- | --- | --- | --- |
| Flow 查看、钻取、详情、分支与历史 | 共享 Host 实现 | 共享 Host 实现 | 共享 Host 实现 |
| 搜索、筛选、标记、对比、回放、导出 | 共享增强 Client | 内嵌 flow 同样提供 | Client 源码 RPC / inline 组装包含相同 helpers |
| 官方 Markdown | 静态模板声明相应依赖 | 按可用注入启用；缺失时保留原文 | 按可用能力降级，不要求额外动态批准 |
| 普通 calc / HTTP / flowedit 等 | 不含这些工具的独立产品 | 原有通用 HTML 面板与动作字段协议 | 原有 registry / loader / 批准 / timer 生命周期 |
| 样式和存储隔离 | 编译 scope + `RT` 命名空间 | Flow 增强局限于目标根 | Flow 增强局限于目标根；不覆盖 flowedit 旧基础类 |
| 已有离线证据 | 静态 bundle、真实 React / DOM、Flow smoke | 显式完整 catalog 构建、calc / HTTP / flowedit、包清单检查 | 规范 source assembly、真实 rc.2 codec / runner、启停清理 |
| 真实用户实例验收 | 待认证页面 | 待单独启用及与 Flowglass 同页验收 | 待目标宿主上的实际加载验收 |

`build/source-assembly.mjs` 统一顺序：`flow-launch.js` → `flow-stable.js` → `client.js`。这些 helpers 为普通脚本，继续支持现有源码拼接方式。普通工具不经过 Flow 专属稳定区域。

Host 回归新增搜索范围、节点类型校验、历史定位、无未来数据的回放、完整输入对齐、失效结论拒绝和恢复轮次定位。真实 rc.2 RPC 还发现并修复了一个 wire 问题：临时非枚举字段不能直接放进返回 `state`；所有正常与错误返回现统一清理。

## 持久事件投影缓存实验

在功能实现后对同一份 1200 事件 fixture 做 20 次预热和 120 次采样，未缓存版 Host 渲染 P50 / P95 为 6.49 / 18.39ms，加入精确源校验的最终缓存版为 3.53 / 5.40ms。实验运行时有并行任务，尤其 P95 受机器负载影响；这是局部暖缓存验证，不是生产延迟承诺，也不替代基线报告中的独立 25 样本矩阵。原始结果为 `.scratch/host-cache-before.json` 与 `.scratch/host-cache-after.json`。

缓存只用于持久事件：匹配 Session、实际返回事件数组身份、长度、计数、末尾 seq、回放位置和完整 JSON 内容；reader 标记变化时重建。即使同一数组原地修改且计数不变，也不会复用旧投影。缓存最多 16 个 Session，单项不超过 200 万字符、总源副本不超过 800 万字符，超过阈值直接重新折叠。live overlay、原始 live-chunk、读取失败或无法 JSON 化的日志不缓存。渲染器拿到顶层节点副本，不能把本次显示状态写回缓存。重试倒计时仍在每次渲染计算。

测试覆盖追加事件、同计数修改 / 替换、reader changed、回放变化、live 绕过、展示规则更新、调用者修改隔离和 16 scope 驱逐。该缓存不扩大底层日志适配器的数据可见范围，也没有改写 Session 格式。
